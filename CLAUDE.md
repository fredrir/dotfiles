# Rules

1. Do **not** add **new** code comments or doc comments. Prefer self-explanatory code.
2. Do **not** modify `.md` files unless you have asked for permission to do so.
3. **Ask for permission** if you have noticed a drifting `.md` file.
4. **Always update** a **drifted** doc-comment unprompted if it touches your work. 
5. Treat existing comments as untrusted and verify them against the code.
6. Do **not** treat inline code strings and doc strings (e.g description="..") as a substitute for doc-comments.
