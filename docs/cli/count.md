# count

## Commands

<!-- cli:commands:start -->
| Command | Description                      |
| ------- | -------------------------------- |
| `count` | Counts items inside a directory. |
<!-- cli:commands:end -->

## Flags

<!-- cli:flags:start -->
| Flag                    | Description                                                                 |
| ----------------------- | --------------------------------------------------------------------------- |
| `-r`, `--recursive`     | Counts every entry below the directory instead of only its direct children. |
| `-d`, `--no-hidden`     | Excludes hidden entries and everything inside hidden directories.           |
| `-h`, `--help`          | Shows help for the selected command and exits.                              |
| `--completions <SHELL>` | Prints a shell completion script for the named shell and exits.             |
| `-V`, `--version`       | Prints the version and exits.                                               |
<!-- cli:flags:end -->
