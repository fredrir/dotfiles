# dotfmt

## Commands

<!-- cli:commands:start -->
| Command  | Description                                                     |
| -------- | --------------------------------------------------------------- |
| `dotfmt` | Formats the `.conf`, `.config`, and `.dotfile` files in a tree. |
<!-- cli:commands:end -->

## Flags

<!-- cli:flags:start -->
| Flag                    | Description                                                                        |
| ----------------------- | ---------------------------------------------------------------------------------- |
| `--check`               | Reports files that are not formatted instead of rewriting them.                    |
| `--stdin <FILENAME>`    | Formats standard input as the named file and writes the result to standard output. |
| `-v`, `--verbose`       | Names every file as it is formatted.                                               |
| `-q`, `--quiet`         | Reports nothing but failures.                                                      |
| `-h`, `--help`          | Shows help for the selected command and exits.                                     |
| `--completions <SHELL>` | Prints a shell completion script for the named shell and exits.                    |
| `-V`, `--version`       | Prints the version and exits.                                                      |
<!-- cli:flags:end -->
