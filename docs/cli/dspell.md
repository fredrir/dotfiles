# dspell

## Commands

<!-- cli:commands:start -->
| Command  | Description                                                                 |
| -------- | --------------------------------------------------------------------------- |
| `dspell` | Prints the misspelled word at or before the cursor and its guesses as JSON. |
<!-- cli:commands:end -->

## Flags

<!-- cli:flags:start -->
| Flag                      | Description                                                     |
| ------------------------- | --------------------------------------------------------------- |
| `-l`, `--lang <LANGUAGE>` | Languages a typo must be misspelled in                          |
| `-h`, `--help`            | Shows help for the selected command and exits.                  |
| `--completions <SHELL>`   | Prints a shell completion script for the named shell and exits. |
| `-V`, `--version`         | Prints the version and exits.                                   |
<!-- cli:flags:end -->
