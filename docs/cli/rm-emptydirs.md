# rm-emptydirs

## Commands

<!-- cli:commands:start -->
| Command        | Description                                        |
| -------------- | -------------------------------------------------- |
| `rm-emptydirs` | Deletes empty directories below the given targets. |
<!-- cli:commands:end -->

## Flags

<!-- cli:flags:start -->
| Flag                    | Description                                                             |
| ----------------------- | ----------------------------------------------------------------------- |
| `--dry`                 | Shows what would go without deleting anything.                          |
| `-y`, `--yes`           | Runs without asking for confirmation.                                   |
| `-v`, `--verbose`       | Lists every row instead of truncating after 12 rows.                    |
| `-a`, `--all`           | Also deletes folders the usual skip list and hidden entries would keep. |
| `-h`, `--help`          | Shows help for the selected command and exits.                          |
| `--completions <SHELL>` | Prints a shell completion script for the named shell and exits.         |
| `-V`, `--version`       | Prints the version and exits.                                           |
<!-- cli:flags:end -->
